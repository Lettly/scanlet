Scanlet Bridge

Your printer, without a server

Scanlet Bridge reaches eSCL / AirScan printers on your own network, so the Scanlet web app can pull scans from a flatbed, a document feeder or a duplexing ADF.

  • Nothing to install and keep running — no helper program, no local server
  • ADF and duplex included, straight from the device
  • Nothing leaves your network — no account, no telemetry, no remote code
