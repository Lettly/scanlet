Running the scanning bridge

The bridge is one Node file with no dependencies. It discovers scanners over Bonjour (_uscan._tcp) and performs eSCL scans — the same driverless protocol macOS AirScan and SANE’s escl backend use.

  1. Download bridge/scanlet-bridge.mjs from this repository.
  2. node scanlet-bridge.mjs — for this machine only.
  3. node scanlet-bridge.mjs --lan — also serves Scanlet to your phone, with a pairing link you can scan as a QR code.
  4. Leave it running and press Connect above.
node scanlet-bridge.mjs --lan

Add --tls to serve over https. A phone needs https for the camera, the service worker and “Add to Home Screen”, because browsers only treat https and localhost as secure.

The bridge only ever talks to printers on your local network, and in --lan mode every request needs the pairing code it prints. Prefer the browser extension on a desktop: it needs no server at all.

About Scanlet

Scanlet is a document scanner and PDF toolkit that runs entirely in your browser. Pages are captured, cleaned, straightened, OCR’d and assembled into a PDF on this device — there is no server to upload to.

It is a static site, so it hosts anywhere: GitHub Pages, an S3 bucket, or a folder on your desk.

  • Camera capture with edge detection and perspective correction
  • eSCL / AirScan scanning through the browser extension or an optional local bridge, including ADF and duplex
  • Deskew, shadow removal, adaptive black & white, auto-crop
  • OCR (Tesseract) with a searchable text layer in the exported PDF
  • Multi-page assembly: reorder, split, merge, rotate, annotate, N-up, watermarks, bookmarks

Self-contained: PDF.js, pdf-lib, Tesseract.js, JSZip and qrcode-generator are vendored into this repository and loaded from it, so the app makes no third-party request at runtime. The diagnostics below confirm it.
